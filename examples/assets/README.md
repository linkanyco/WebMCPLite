# Example artwork

`collaboration-banner.png` was generated using the built-in image_gen tool for this project on 2026-10-27. It depicts a human store administrator and a computer character discussing one shared webpage. The selected asset is saved locally and bundled by Vite. No customer images or private screenshots were used.

Generation prompt (condensed; exact requests are in [generation.json](generation.json)):

> A wide landing-page banner: a friendly cartoon human store administrator and anthropomorphic desktop computer character discussing and pointing together at one shared ecommerce admin webpage. Polished editorial comic illustration, crisp hand-drawn black outlines, warm off-white paper, soft lavender and peach accents. Relaxed collaboration, speech bubbles with abstract shapes, no readable text, no logos or watermark.

Targeted edit prompt:

> Change only the product icons on the shared webpage from clothing, a bag and shoe to a computer keyboard, USB hub and desk lamp, plus the existing plant. Use a keyboard detail thumbnail. Preserve the characters, layout, style, colors and framing. No readable text.

The storefront seed separately references three decorative photos directly from images.unsplash.com. They are not bundled or copied into the repository. The preview needs network access for these images. Their original photo IDs are preserved in workspace.js.
